# Remedy Cooling & Heating — Brand Guide

## Colors

| Name | Hex | Usage |
|---|---|---|
| Remedy Red | `#CC2222` | Logo "R", Rx mark, all CTAs, buttons, phone links |
| Remedy Navy | `#1B3899` | "COOLING & HEATING", nav, headers, footer bg |
| Remedy Dark | `#0F2461` | Footer background, dark overlays |
| Mist | `#F4F7FA` | Alternating section backgrounds |
| Emergency Red | `#CC2222` | Emergency band (same as brand red) |
| White | `#FFFFFF` | Page background |
| Ink | `#1A2430` | Body text |

**Rule:** Red is reserved for action (CTAs, phone numbers, emergency). Navy is structure (nav, footer, headers). Never mix them on the same element.

## Logo

**Files:**
- `remedy-logo.jpg` — Full-color logo (navbar, print, van, web)
- `remedy-logo.svg` — Inline SVG component (`components/Logo.tsx`)

**Logo concept:** The Rx prescription mark with a heartbeat/EKG line — a visual pun on "Remedy." Red Rx mark + bold REMEDY wordmark + navy COOLING & HEATING.

**Usage rules:**
- Never stretch or distort
- Minimum height: 40px web / 1 inch print
- On dark backgrounds: use white/inverted version (`brightness-0 invert` CSS filter)
- On colored backgrounds: use white version only
